카카오 REST API 키

좌표 변환용 · 무료 · 1~5분
받는 방법
  1. developers.kakao.com/console/app 접속 (카카오 로그인)
  2. "내 애플리케이션" → 이미 만들어둔 비데앱 클릭 (Android 키 발급할 때 만든 그 앱) — 없으면 "애플리케이션 추가"
  3. 왼쪽 메뉴 "앱 설정 → 앱 키"
  4. REST API 키 행에 있는 32자 문자열 복사
채팅에 붙여넣을 때 형식 
KAKAO_REST_API_KEY: 여기에_32자_hex
✨ 이거 받으면 즉시 효과
좌표 없는 휴게소/지방 데이터에 좌표 채워줌. JSON이 6건 → 10건+ 로 늘어남. 
python pipeline.py geocode
python firestore_adapter.py

Claude API 키 (Anthropic)

LLM 추출 · 신규 가입 $5 무료 크레딧 · 우리 작업 약 $0.10 · 5~10분
받는 방법
  1. console.anthropic.com 접속 (없으면 가입, Google 로그인 가능)
  2. 가입 직후 자동 $5 크레딧 지급됨 (충분히 남음)
  3. 좌측 API Keys 메뉴 → Create Key
  4. 이름은 아무거나 (예: "bidet-app") → Create
  5. 한 번만 보여주는 키 복사 (sk-ant-api03-... 로 시작)
채팅에 붙여넣을 때 형식 
ANTHROPIC_API_KEY: sk-ant-api03-...
🚀 이거 받으면 데이터 양 폭발
현재 룰베이스가 못 잡은 779건 raw_documents 를 Claude Haiku 로 다시 처리 → 양질 데이터 50~200건 추출 예상. 
# 노이즈 정리 후 LLM 재추출
python _cleanup_naver.py
python pipeline.py extract     # 이때부터 LLM 모드
python firestore_adapter.py    # JSON 갱신

google-services.json (Firebase)

안드 앱이 Firebase 연결 · 무료 · 10~15분
받는 방법
  1. console.firebase.google.com → 프로젝트 추가
  2. 프로젝트 이름: bidet-app → 만들기 (Google Analytics 켜도 끄도 상관 X)
  3. 대시보드에서 Android 아이콘 🤖 클릭해서 앱 추가
    • 패키지명: com.bidet.app
    • 닉네임: 비데앱
    • SHA-1: 아래 줄 복사해서 붙여넣기 ↓
  4. "앱 등록" 클릭 → 다음 단계에서 google-services.json 다운로드
  5. 좌측 메뉴 Build → Firestore Database → 시작 → 테스트 모드 → 위치: asia-northeast3 (서울)
안드 앱 SHA-1 (Firebase 등록 시 입력)
F1:7A:31:13:92:8B:E2:B8:1D:57:2A:88:86:75:15:CF:7C:20:72:A4 클릭→전체선택
채팅에 어떻게 전달?
  1. 다운받은 google-services.json 을 채팅 창에 드래그&드롭 (간편) 또는
  2. 직접 mobile/app/google-services.json 경로에 저장하고 채팅에 "배치 완료" 라고 알려주기
🎯 이거 받으면 — 데모 모드 OFF
mobile/app/build.gradle.kts 가 자동 감지해서 BuildConfig.DEMO_MODE = false 로 빌드. 진짜 Firestore 에서 데이터 받음.

service-account.json (Firebase Admin)

Python에서 Firestore 적재 · 1~2분
받는 방법 (Firebase 프로젝트 생성 후)
  1. Firebase Console → 프로젝트 설정 (좌측 상단 톱니바퀴)
  2. 서비스 계정 탭
  3. "새 비공개 키 생성" 클릭 → JSON 다운로드 (주의: 비밀 키이므로 절대 외부 공유 X, git 에도 안 올라감)
채팅에 어떻게 전달?
  1. 다운받은 service-account.json 을 채팅 창에 드래그&드롭
  2. 또는 backend/service-account.json 경로에 저장하고 "배치 완료" 알려주기
🏁 마지막 단계 — 폰에서 진짜 데이터
python firestore_upload.py            # 6+건 Firestore 적재
cd mobile && .\gradlew installDebug   # 폰에 새 빌드 (Firebase 모드)

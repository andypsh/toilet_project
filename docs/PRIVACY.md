# 비데앱 개인정보 처리방침

**최종 업데이트: 2026-06-03**

비데앱(이하 "본 서비스")은 전국 공중화장실 중 비데가 설치된 곳을 지도에서 찾을 수 있도록 돕는 위치기반 안드로이드 애플리케이션입니다. 본 처리방침은 본 서비스가 수집·이용·보관하는 개인정보의 내용과 처리 방식을 설명합니다.

---

- **서비스명:** 비데앱
- **운영자:** (운영자 이름 또는 단체 — 출시 전 채워넣을 것)
- **문의 이메일:** (담당자 이메일 — 출시 전 채워넣을 것)

## 2. 수집하는 개인정보 항목

### 2.1 회원가입 및 로그인 시 수집
구글 또는 카카오 계정 연동을 통해 다음 정보를 자동으로 수집합니다.

| 항목 | 출처 | 목적 |
|------|------|------|
| 이메일 주소 | Google / Kakao OAuth | 계정 식별, 중복 가입 방지 |
| 닉네임 | Google / Kakao OAuth | 리뷰·제보 작성자 표시 |
| 프로필 사진 URL | Google / Kakao OAuth | 사용자 식별용 아바타 표시 (선택) |
| 인증 제공자(provider) | Google / Kakao OAuth | 로그인 경로 구분 |
| 사용자 고유 ID(uid) | Firebase Authentication | 내부 식별자 |

### 2.2 서비스 이용 중 수집
| 항목 | 수집 시점 | 목적 |
|------|----------|------|
| 위치 정보(GPS 좌표) | 사용자가 위치 권한 허용 후 지도 사용 시 | 현재 위치 주변 비데 화장실 검색 |
| 사용자 제보(위치·사진·설명) | 사용자가 직접 입력·전송 시 | 화장실 정보 등록, 비데 유무 업데이트 |
| 리뷰(평점·사진·코멘트) | 사용자가 직접 입력·전송 시 | 다른 사용자에게 화장실 정보 제공 |
| 즐겨찾기 화장실 목록 | 사용자가 즐겨찾기 등록 시 | 개인화된 즐겨찾기 기능 제공 |

### 2.3 자동 수집 항목
| 항목 | 수집 도구 | 목적 |
|------|----------|------|
| 앱 사용 통계(화면 진입, 이벤트 빈도) | Firebase Analytics | 서비스 개선, 오류 분석 |
| 기기 식별자, OS 버전, 앱 버전 | Firebase Analytics | 호환성 분석 |

## 3. 개인정보의 이용 목적

- 회원 식별 및 본인 확인
- 위치 기반 화장실 검색 서비스 제공
- 사용자 제보·리뷰 기능 제공 및 공개
- 서비스 품질 개선, 오류 진단, 통계 분석
- 부정 이용 방지

---

## 4. 위치 정보의 처리 (위치정보의 보호 및 이용 등에 관한 법률)

- 본 서비스는 사용자의 명시적 동의(앱 권한 다이얼로그) 후에만 위치 정보를 수집합니다.
- 수집된 위치 좌표는 **서버에 저장되지 않으며**, 기기 내에서 화장실 검색 요청 시 일시적으로 사용된 후 폐기됩니다.
- 사용자가 직접 "이 위치에 화장실이 있어요" 형태로 제보한 좌표는 제보 데이터의 일부로 저장되어 다른 사용자에게 공개됩니다.
- 사용자는 언제든지 안드로이드 설정 > 앱 > 비데앱 > 권한에서 위치 권한을 철회할 수 있습니다.

---

## 5. 개인정보의 보관 및 파기

- **회원 정보**: 회원 탈퇴 시까지 보관, 탈퇴 즉시 파기
- **사용자가 작성한 제보·리뷰**: 작성 후 영구 보관 가능 (서비스 공익성). 본인이 삭제 요청 시 즉시 삭제
- **자동 수집 통계**: Firebase Analytics 정책에 따라 최대 14개월 보관 후 자동 삭제
- **파기 방법**: 전자적 파일은 복구 불가능한 방식으로 영구 삭제

---

## 6. 개인정보의 제3자 제공 및 처리 위탁

본 서비스는 사용자 동의 없이 개인정보를 외부에 제공하지 않습니다. 단, 서비스 운영을 위해 다음 업체에 처리를 위탁합니다.

| 수탁자 | 위탁 항목 | 위탁 업무 |
|--------|----------|----------|
| Google LLC (Firebase) | 계정 정보, 제보·리뷰 데이터, 통계 | 서버 호스팅, 인증, 데이터베이스, 분석 |
| Kakao Corp. | OAuth 토큰 | 카카오 로그인 연동 |
| Kakao Corp. (카카오맵) | 좌표 → 주소 변환 요청 | 지도 표시 및 주소 검색 |

## 7. 사용자의 권리

사용자는 언제든지 다음 권리를 행사할 수 있습니다.

- 자신의 개인정보 열람·정정·삭제 요청
- 처리 정지 요청
- 회원 탈퇴 (앱 내 설정 > 계정 > 회원 탈퇴)
- 위치 권한 등 개별 권한 철회 (안드로이드 시스템 설정)

권리 행사는 위 1번의 문의 이메일로 연락 주시면 지체 없이 처리합니다.

## 8. 어린이 개인정보 보호

본 서비스는 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 만 14세 미만으로 확인된 계정은 발견 즉시 삭제 처리됩니다.

## 9. 보안 조치

- Firebase 보안 규칙으로 데이터 접근을 통제합니다.

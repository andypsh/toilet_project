6개인정보처리방침 초안DONE

위치권한 + Firebase Auth 쓰면 Play Console 필수 자료
  • 초안 위치: docs/PRIVACY.md
  • 너가 마무리할 것: 상단 "운영자 이름"과 "문의 이메일" 채우기 (가짜 넣으면 심사 거부됨)
  • 호스팅: GitHub Pages 또는 Notion 공개 페이지 → 공개 URL 확보 필요
진행 필요 — 코드/키 단계

1릴리즈 키스토어 생성YOU

앱 서명용 .jks 파일. 비번을 내 컨텍스트에 남기지 않으려면 네가 직접 실행 추천.
cd C:\Users\andyp\Desktop\고려대\비데앱\mobile
.\scripts\create_keystore.ps1
  • 대화형으로 비번 2개 (storePassword, keyPassword) 입력
  • 이름/조직/도시 등은 아무거나 입력해도 됨
  • 완료 후 keystore.properties.example을 keystore.properties로 복사하고 비번 채우기
⚠️ 절대 잃지 말 것: .jks 파일 + 비번 둘 다. 분실 시 같은 패키지명으로 영구 업데이트 불가. 외장하드 또는 1Password에 백업.

2Firebase 프로젝트 연결YOU

현재 DEMO_MODE=true. 실제 서비스 출시하려면 진짜 Firebase 연결 필수.
  • console.firebase.google.com → 새 프로젝트 생성
  • Android 앱 추가 → 패키지명 com.bidet.app
  • 릴리즈 SHA-1 등록 (#1 완료 후 내가 추출해줌)
  • google-services.json 다운로드 → mobile/app/ 에 배치
  • Firestore + Authentication(Google, Kakao 둘 다) + Storage + Analytics 활성화
  • Firestore 보안 규칙: 프로덕션 모드로

3카카오 개발자 콘솔 릴리즈 키해시 등록YOU

디버그 키해시만 등록돼 있으면 릴리즈 빌드에서 카카오맵/로그인이 깨짐.
  • developers.kakao.com → 내 애플리케이션 → 비데앱
  • 플랫폼 → Android → 키해시 추가 (#1 완료 후 내가 base64 변환해줌)
  • "카카오 로그인" 기능 활성화 확인
  • 카카오맵 SDK Native App Key가 mobile/local.properties 에 들어있는지 확인

4Google Cloud OAuth 릴리즈 SHA-1 등록YOU

Google Sign-In용. Firebase가 자동으로 만든 OAuth 클라이언트에 릴리즈 SHA-1 추가해야 함.
  • console.cloud.google.com/apis/credentials
  • Firebase 프로젝트와 동일한 GCP 프로젝트 선택
  • OAuth 2.0 클라이언트 ID (Android 타입) 편집 → SHA-1 인증서 지문에 릴리즈용 추가
  • 웹 클라이언트 ID는 mobile/local.properties의 GOOGLE_WEB_CLIENT_ID에 이미 있어야 함

5릴리즈 AAB 빌드 + 실기기 테스트BOTH

#1~#4 완료 후 빌드 가능. AAB는 직접 설치 불가 → bundletool로 APK 추출 후 실기기에서 검증.
cd mobile
.\gradlew bundleRelease
# 결과: mobile/app/build/outputs/bundle/release/app-release.aab
  • 내가 가능: 빌드 명령 실행, 에러 디버깅, 결과물 위치 확인
  • 너만 가능: 폰 USB 연결, 실기기에서 골든패스 (로그인 → 위치권한 → 지도 → POI 확인 → 제보·리뷰)
bundletool 설치: winget install Google.BundleTool 또는 GitHub releases에서 jar 다운로드
진행 필요 — Play Console 단계

8Google Play 개발자 계정 등록YOU

앱 업로드 전제조건. 신규 개인 계정이면 비공개 테스트 14일 필수.
  • play.google.com/console/signup
  • $25 일회성 결제 (신용카드)
  • 신분 확인 (여권 또는 신분증)
  • 개인 / 단체 선택 — 개인이면 신규 정책상 14일 비공개 테스트 + 테스터 12명 이상 필수
고려대 프로젝트라 단체로 등록한다면 사업자 정보 필요 — 학생/개인이면 그냥 개인 계정

7스토어 등재 자료 준비BOTH

앱 페이지에 노출될 이미지/카피. 부실하면 심사 통과해도 다운로드 안 받음.
  • 아이콘: 512×512 PNG (현재 mipmap-anydpi-v26/ic_launcher.xml 기반으로 추출 필요)
  • 피처 그래픽: 1024×500 PNG (앱 페이지 상단 배너)
  • 스크린샷: 폰 2~8장, 16:9 또는 9:16
  • 짧은 설명: 80자 — 예: "전국 공중화장실 중 비데 설치된 곳을 지도에서 한눈에"
  • 자세한 설명: 4000자 — 기능, 사용법, 데이터 출처(서울시 공공데이터)
  • 카테고리: 여행 및 지역정보 / 라이프스타일 중 택1
  • 내가 가능: 카피라이팅 초안, 카테고리 추천
  • 너만 가능: 스크린샷 촬영 (실기기 또는 에뮬레이터)

9Play Console 설문 3종YOU

데이터 안전 + 콘텐츠 등급 + 타겟 사용자. 모두 답변해야 출시 가능.
  • 데이터 안전 섹션: 이메일/이름/사진/위치/사용자 콘텐츠/Analytics 수집 신고 — 내가 답변 초안 만들어줄 수 있음
  • 콘텐츠 등급 (IARC): 폭력/성/도박 등 설문. 비데앱은 전체이용가 예상
  • 타겟 사용자: 만 13세 이상 일반, 어린이 대상 아님
